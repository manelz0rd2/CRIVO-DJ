# Contribuindo com o CRIVO DJ

Obrigado por ajudar a melhorar o CRIVO DJ. Durante o beta fechado, a melhor contribuição é um relato reproduzível e cuidadoso.

## Antes de abrir um relato

1. Confirme que está usando a versão mais recente disponível em **Releases**.
2. Use **Verificar ambiente** na seção final da aba Organizar.
3. Tente reproduzir o problema com uma cópia dos arquivos, nunca com a única cópia da biblioteca.
4. Exporte o diagnóstico pelo próprio CRIVO DJ.

## Um bom relato contém

- versão do Windows e do CRIVO DJ;
- aba e botão utilizados;
- resultado esperado e resultado observado;
- passos mínimos para reproduzir;
- mensagem mostrada na interface;
- diagnóstico exportado, depois de conferir o conteúdo do ZIP.

Não publique chaves, cookies, links privados de playlists, bancos do Rekordbox, arquivos de áudio ou caminhos pessoais.

## Pull requests

- mantenha compatibilidade com Windows PowerShell 5.1;
- preserve o comportamento portátil e sem privilégios administrativos;
- não inclua binários, caches, logs ou dados reais de biblioteca;
- adicione ou atualize testes quando mudar comportamento;
- execute a suíte descrita no README antes de enviar;
- explique riscos para arquivos e para o banco do Rekordbox.

Ao contribuir, você declara ter direito de enviar o conteúdo. A aceitação de código não concede uma licença geral sobre o restante do projeto.
